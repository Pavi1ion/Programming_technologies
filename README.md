Лабораторная работа №3 – Цены на топливо (обработка ошибок, логирование, тесты)

Описание программы

Программа с графическим интерфейсом (Tkinter) для работы со списком цен на топливо.  
Данные хранятся в текстовом файле `data.txt` в формате:
"тип топлива" ГГГГ.ММ.ДД цена

Пример корректной строки: `"АИ-95" 2025.03.12 45.67`

Нововведения Lab3 по сравнению с Lab2

- Собственное исключение `FuelPriceParseError` – выбрасывается при неверном формате строки.
- Логирование ошибок – все некорректные строки из файла и ошибки при добавлении через GUI записываются в файл `errors.log` с указанием времени и содержимого.
- Модульные тесты – покрывают парсинг строк и загрузку данных из файла (игнорирование некорректных строк).
- Разделение модели и представления – модель (`FuelPrice`, `DataHandler`) не зависит от GUI и может тестироваться отдельно.
- Запуск тестов через аргумент командной строки `--test`.

Требования

- Python 3.7 или новее.
- Tkinter (входит в стандартную установку Python; на Linux может потребоваться `sudo apt install python3-tk`).

Запуск GUI

python lab3.py
Запуск тестов
bash
python lab3.py --test
или напрямую через unittest:

bash
python -m unittest test_model.py

Интерфейс
Таблица – отображает загруженные объекты.

Поле ввода – для добавления новой строки в строгом формате.

Кнопки «Добавить» / «Удалить» – добавление с проверкой, удаление выделенной строки.

Статус-бар – отображает краткие сообщения о действиях.

Лог-файл errors.log – создаётся автоматически, содержит все ошибки формата (дата, время, описание, строка).

Обработка ошибок
При загрузке data.txt все невалидные строки пропускаются, информация о них записывается в errors.log. Программа не падает.

При добавлении через GUI:

Пустая строка – предупреждение.

Неверный формат – диалог с ошибкой, запись в лог.

Дубликат (совпадение типа, даты и цены) – предупреждение, без добавления.

Структура кода
lab3.py – точка входа. Если передан аргумент --test – запускаются тесты, иначе открывается GUI.

model.py – классы FuelPrice (хранение/парсинг) и DataHandler (загрузка/сохранение), собственное исключение FuelPriceParseError, логирование ошибок.

view.py – главное окно на Tkinter, обработка событий, вызов методов модели.

test_model.py – модульные тесты (unittest) для FuelPrice и DataHandler.

data.txt – файл с данными.

errors.log – файл лога (создаётся автоматически).

Код соответствует принципу SRP и стилю PEP8.
