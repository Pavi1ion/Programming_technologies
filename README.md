Лабораторная работа №2 – Цены на топливо

Описание программы

Программа с графическим интерфейсом (Tkinter) для работы со списком цен на топливо.  
Данные хранятся в текстовом файле `data.txt` в формате:
"тип топлива" ГГГГ.ММ.ДД цена

Пример корректной строки:  
"АИ-95" 2025.03.12 45.67

Возможности

- Просмотр всех объектов в виде таблицы (Тип, Дата, Цена).
- Добавление нового объекта через поле ввода с проверкой формата и дубликатов.
- Удаление выделенного объекта из таблицы.
- Автоматическое сохранение изменений в файл `data.txt`.

Требования

- Python 3.7 или новее.
- Tkinter (входит в стандартную установку Python; на Linux может потребоваться `sudo apt install python3-tk`).

Запуск

1. Убедитесь, что в папке с программой есть файл `data.txt` (см. пример ниже) или он будет создан автоматически при первом сохранении.
2. Выполните в терминале:
   python lab2.py
Пример файла data.txt

"АИ-92" 2025.01.10 42.50
"АИ-95" 2025.02.15 45.67
"ДТ" 2025.03.01 48.80
Интерфейс
Таблица – отображает все загруженные объекты.

Поле ввода – для ввода новой строки в строгом формате.

Кнопка «Добавить» – добавляет объект после проверки.

Кнопка «Удалить» – удаляет выделенную строку.

Статус-бар – показывает краткие сообщения (загрузка, сохранение, ошибки).

Структура кода
lab2.py – точка входа, запуск окна.

model.py – класс FuelPrice (хранение и парсинг) и DataHandler (загрузка/сохранение).

view.py – главное окно на Tkinter, обработка событий.

data.txt – файл с данными.

README.md – этот файл.

Код соответствует принципу SRP (Single Responsibility Principle) и стилю PEP8.

Обработка ошибок
При некорректной строке в файле data.txt программа пропускает её и выводит предупреждение в консоль.

При добавлении через интерфейс выполняется проверка формата с помощью регулярного выражения; при ошибке выводится диалог.

Дубликаты (совпадение всех трёх полей) не допускаются – программа покажет предупреждение.
