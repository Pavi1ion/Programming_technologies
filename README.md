Лабораторная работа №4 – Обработка команд из файла (ADD, REM, SAVE)

Описание

Программа с графическим интерфейсом (Tkinter) для управления списком цен на топливо.  
Новое: поддержка текстового файла с командами:

- `ADD тип; дата; цена` — добавить объект (CSV-формат)
- `REM условие` — удалить все объекты, удовлетворяющие условию (например, `price < 100`, `type == "АИ-95"`, `date > 2025.01.01`)
- `SAVE путь/к/файлу` — сохранить текущий список в указанный файл (в CSV-формате)

Команды выполняются последовательно. После каждой команды таблица данных обновляется. Данные, загруженные из `data.txt` и изменённые через GUI, используются как основа.

Требования

- Python 3.7+
- Tkinter (входит в стандартную установку)

Запуск GUI

python lab4.py

Формат командного файла (пример commands.txt)
text
ADD АИ-98; 2025.04.01; 55.00
REM price > 48
SAVE filtered_data.txt
ADD ДТ; 2025.05.01; 52.30
Условия для REM
Поля: type (строка), date (дата в формате ГГГГ.ММ.ДД), price (число)

Операторы: ==, !=, <, >, <=, >=

Примеры:

type == "АИ-95"

date > 2025.02.01

price < 50

Структура кода
lab4.py – точка входа (GUI или тесты)

model.py – классы FuelPrice, DataHandler, ConditionParser, CommandProcessor

view.py – главное окно на Tkinter (кнопка «Выполнить команды из файла»)

test_model.py – модульные тесты (unittest)

data.txt – файл с исходными данными

errors.log – лог ошибок (создаётся автоматически)
